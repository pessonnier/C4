# WeakC4 reference data

`branches.json`, `steady_states.json`, and `positions.txt` are copied from the
[2swap/WeakC4](https://github.com/2swap/WeakC4) repository. They remain the
compact source of truth (plus the original spatial layout); `dist/graph.json`
is generated and is intentionally ignored by Git.
